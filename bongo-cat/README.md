# Bongo Cat для OBS

Прозрачный кот для захвата окном в OBS. Он реагирует на всю клавиатуру, на левую и правую кнопки мыши и на громкость микрофона.

Картинки по умолчанию — заглушки, чтобы сразу было видно, как слои складываются. Свои PNG кладутся в ту же папку `assets` с теми же именами.

## Как обойтись без картинки на каждую клавишу

Отдельный кадр на каждую кнопку не нужен. Лапа — это маленький спрайт, а программа сама ставит его на нажатую клавишу.

Нужны три файла:

| Файл | Когда виден |
| --- | --- |
| `hand/idle.png` | Клавиатурой не пользуются, рука опущена |
| `hand/press.png` | Палец на клавише |
| `hand/raised.png` | Рука поднята между нажатиями |

На всех трёх картинках палец должен быть в одной и той же точке. По умолчанию это середина по горизонтали и почти нижний край (якорь 0.50, 0.92). В настройках можно поменять якорь и прямоугольник клавиатуры: включите «Показать сетку клавиш» и «Двигать и менять размер».

Если для отдельных клавиш нужен свой рисунок, положите файл в `hand/keys/`. Имя — как у клавиши в Windows, например `A.png`, `Space.png`, `LeftShift.png`, `D1.png`. Такой файл важнее общей лапы. Ещё можно положить четыре варианта по зонам: `hand/zones/left.png`, `center.png`, `right.png`, `space.png`. Они используются, только если для конкретной клавиши своего файла нет.

Если картинка лапы того же размера, что и тело, она считается уже собранным слоем и ставится на весь холст, без сдвига.

## Остальные картинки

Тело, челка, рот, глаза и мышь — полноразмерные PNG с прозрачным фоном, все одного размера. Они уже нарисованы на своих местах и просто сменяются.

```
assets/
  body.png
  bangs/1.png
  bangs/2.png
  bangs/3.png
  mouth/closed.png
  mouth/half.png
  mouth/open.png
  eyes/open.png
  eyes/half.png
  eyes/closed.png
  mouse/idle.png
  mouse/left.png
  mouse/right.png
  hand/idle.png
  hand/raised.png
  hand/press.png
```

Порядок слоёв снизу вверх: тело, рот, глаза, челка, мышь, лапа клавиатуры.

## Как это двигается

- Челка проигрывает три кадра, каждый по 0,5 с, потом 5 с паузы на первом кадре, и так по кругу.
- Рот: тишина — закрыт. Тихая речь — только закрытый и полуоткрытый. Громкая речь — закрытый, полуоткрытый и открытый.
- Лапа: при нажатии клавиши кадр «палец на клавише» (по умолчанию 0,3 с), затем поднятая рука. Если клавиши больше не жмут, рука опускается. Повтор одной и той же клавиши не держит палец нажатым. При быстрой печати поставьте «Нажатие» 100–150 мс, иначе лапа не успеет подняться между буквами.
- Глаза моргают тремя кадрами: полузакрытый, закрытый, полузакрытый. Пауза между морганиями каждый раз случайная. Иногда моргание двойное.
- Мышь: без клика, левая кнопка, правая кнопка. Если зажаты обе, видна та, которую нажали последней.

Пороги микрофона и все интервалы крутятся в окне настроек. Окно прячется в трей, из трея же программа закрывается.

## OBS

1. Соберите и запустите программу на Windows.
2. В OBS добавьте источник «Захват окна» и выберите **Bongo Cat**.
3. На зелёный фон (#00FF00) повесьте фильтр «Хромакей».

Хромакей надёжнее настоящей прозрачности. Прозрачность без зелёного фона включается в настройках пунктом «Настоящая прозрачность»; после этого в OBS нужен захват, который сохраняет альфа-канал.

Пока кот в режиме «клики проходят сквозь», его можно не бояться: он не перехватывает мышь. Чтобы перетащить окно, включите «Двигать и менять размер» и потяните белый квадрат в правом нижнем углу.

## Сборка

Нужен .NET 8 SDK на Windows.

```bash
cd bongo-cat
dotnet run --project src/BongoCat.App
```

Публикация рядом с папкой `assets`:

```bash
dotnet publish src/BongoCat.App -c Release -r win-x64 --self-contained false
```

Запускайте `BongoCat.exe` из папки публикации. Свои PNG кладите в `assets` рядом с exe и нажмите «Перезагрузить картинки». Файл `settings.json` появится там же.

Проверка логики анимации без окна:

```bash
dotnet test tests/BongoCat.Core.Tests
```

Заглушки можно нарисовать заново:

```bash
python3 tools/make_placeholders.py
```
